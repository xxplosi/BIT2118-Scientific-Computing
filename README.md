BIT 2118 — Scientific Computing Project Overview

This project demonstrates numerical methods and scientific computing techniques using Python, NumPy, SciPy, and Matplotlib.

Objectives Perform numerical calculations using NumPy arrays. Compare numerical methods and investigate numerical errors. Solve linear and nonlinear equations. Apply interpolation, curve fitting, differentiation, and integration. Solve ordinary differential equations. Apply numerical optimization and Monte Carlo simulation. Interpret numerical outputs and graphical results. Project Structure code/ — Python programs for the scientific computing tasks. results/ — Generated graphs and numerical output records. documentation/ — Task explanations, parameter experiments, and the related real-world application. requirements.txt — Python dependencies. .gitignore — Files excluded from Git tracking. Installation

Install Python 3 and Git for Windows.

Create and activate a virtual environment:

python -m venv .venv

Windows Command Prompt:

.venv\Scripts\activate.bat

Install the dependencies:

python -m pip install -r requirements.txt

Running a Program

For example:

python code/Task_02_numpy_arrays.py

Run other tasks by replacing the filename with the required program.
